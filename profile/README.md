## From a question to an answer you can explain.

**SyneHQ is an AI analytics workspace in the cloud.** We're building a shared place for people to ask questions about their data, inspect the work behind an answer, and turn it into something their team can use.

Ask in plain English with **Kole**. Explore with SQL and Python in **Quantum Lab**. Keep the query, results, and explanation together so the next person can check the work and build on it.

Our vision is simple: **make good data work easier to do, understand, and share.** A business question should not get stuck in a queue. An AI-generated answer should come with work you can inspect. And a useful analysis should give the next person a starting point.

[See a worked example](https://synehq.com/demo/) · [Explore the workspace](https://synehq.com/products/)

## Open tools for people who build with data.

We're also building tools that developers can use in their own applications. Querying data, moving results, and collecting events are problems worth solving in the open. You should be able to read the code, run an example, and help make it better.

### Start with Kelvo

**Your databases. One query gateway.**

[Kelvo](https://github.com/SyneHQ/kelvo-go) is our open-source Go analytics gateway. Query databases directly, join supported sources with DuckDB, or reuse Parquet snapshots. Get typed Apache Arrow results for notebooks, dashboards, agents, and APIs.

Use its HTTP API or Go SDK in your own application; your application keeps responsibility for authentication, authorization, and credentials. Kelvo is in **developer preview**. Read the [source coverage](https://github.com/SyneHQ/kelvo-go/blob/cargo/docs/source-coverage.md) and [delivery status](https://github.com/SyneHQ/kelvo-go/blob/cargo/docs/production-roadmap.md#delivery-status) before choosing a deployment.

**Try a real example:** the [15 notebook lessons](https://github.com/SyneHQ/kelvo-go/blob/cargo/notebooks/README.md) cover SQL, joins, data-quality checks, Arrow, and API integration. They include public data, setup, answer checks, and cleanup.

[Run your first query in Colab →](https://colab.research.google.com/github/SYNEHQ/kelvo-go/blob/cargo/notebooks/01-first-query.ipynb)

## Bring a question. Show your work.

**Data Checks by SyneHQ** is our community for SQL, analytics, and data engineering. Any stack is welcome. No SyneHQ subscription required.

- **Learn:** try the [free SQL field guide](https://synehq.com/learn/) with fictional datasets and expected results.
- **Discuss:** bring a query, a small safe example, and the result you expected to [Discord](https://discord.gg/vRfkWAWrNn).
- **Contribute:** improve a connector, reproduce a bug, add an answer check, or make a confusing explanation clearer. Start with the [Kelvo contribution guide](https://github.com/SyneHQ/kelvo-go/blob/cargo/CONTRIBUTING.md) or the guide in your chosen repository.

You don't need a big feature to make a useful contribution. A small example that helps someone understand their data is a good place to start.
