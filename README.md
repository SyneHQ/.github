# Answers your team can check.

SyneHQ is an AI analytics workspace in the cloud. We're building tools that help teams ask questions about data, inspect the work, and share what they learn.

This repository holds our [public GitHub organization profile](https://github.com/SyneHQ), its [README](profile/README.md), and the artwork behind it.

[Explore the workspace](https://synehq.com/) · [Build with Kelvo](https://github.com/SyneHQ/kelvo-go) · [Join Data Checks](https://synehq.com/community/)

## Updating this profile

- Edit `profile/README.md` for the public organization page. Keep product claims grounded in the linked project documentation.
- Keep images in `profile/assets/` so they are publicly accessible without website-repository access.
- Read [the artwork notes](brand/README.md) before changing the logo or banner.

The profile uses the approved S02 symbol, Newsreader wordmark, and wine, ivory, blush, and coral palette. A compact banner is supplied for narrow screens; meaningful text is also available in the README and image descriptions.
